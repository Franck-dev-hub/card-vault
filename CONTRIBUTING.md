# Contributing

Welcome. Card Vault is a monorepo with three stacks (Symfony API, Angular
frontend, FastAPI ML service) orchestrated with Docker Compose.

## Quick start

See [Installation](docs/getting-started/installation.md) to run the dev stack.
The full [contributing guidelines](docs/contributing/guidelines.md) cover language, commit format and code conventions.

## Where to go

| I need to...                | Go to                                                |
|-----------------------------|------------------------------------------------------|
| Run the project locally     | [Installation](docs/getting-started/installation.md) |
| Understand the architecture | [Overview](docs/architecture/overview.md)            |
| Add a feature or fix a bug  | [Guidelines](docs/contributing/guidelines.md)        |
| See what is planned         | [Roadmap](docs/contributing/roadmap.md)              |

Bug reports and feature requests go through [GitHub issues].
Security issues: never open a public issue, follow the [security policy] instead.

[GitHub issues]: https://github.com/Franck-dev-hub/card-vault/issues
[security policy]: SECURITY.md
