# License the code under AGPL-3.0 and protect the brand

The code is open source under AGPL-3.0, and the [trademark policy](../../TRADEMARK.md) keeps the Card Vault name and logo out of that licence.\
The AGPL is the only common open source licence that makes a hosted, modified copy publish its code; the trademark policy stops that copy from passing itself off as Card Vault.\
No open source licence can forbid other deployments: that would take a source-available licence, and the project would stop being open source.

## Considered options

- MIT: a closed hosted clone would owe nothing back.
- GPL-3.0: same gap, since hosting a service is not distributing it.
- FSL (Functional Source License): blocks competing deployments, but is not open source.

## Consequences

- Changing the licence later needs the consent of every contributor whose code is merged.
